# OimoBBSの文書

利用者向けの操作、管理者向けの手順、開発者向けの仕様を目的別にまとめています。必要な文書から読み始められます。

## 最初に読む文書

| やりたいこと | 読む順番 |
| --- | --- |
| 掲示板を読む・書き込む・削除を依頼したい | [掲示板の使い方](user-guide.md) |
| まず手元で試したい | [ローカルの起動例](../README.md#ローカルで試す) → [起動後の確認](setup.md#起動後の確認) |
| 新しいサーバーへ導入したい | [Dockerなし](setup.md) または [Docker](../deploy/README.md) → [起動後の確認](setup.md#起動後の確認) |
| 管理画面で設定・記録を確認したい | [管理画面の使い方](admin-guide.md) → 必要に応じて機能別仕様 |
| 稼働中のサイトを管理したい | [運用手順](operations.md) → 必要に応じて[設定一覧](configuration.md)・[管理者の権限](admin-permissions.md) |
| レスを削除したい・投稿者を規制したい | [レスとスレッドの管理](admin-guide.md#レスとスレッドを管理する) → [原本の扱い](features/records.md#レス削除あぼーんと原本) |
| スレッドを落とす・保存容量を確認したい | [削除と回収の違い](features/records.md#公開停止と保存データの回収) → [容量の確認手順](operations.md#保存容量を確認する) |
| 投稿・接続ログを提出したい | [提出用ログの取得](admin-guide.md#提出用ログを取得する) → [CSV列と署名ZIP](features/records.md#提出用ファイル) |
| 動作のルールを知りたい | [仕様の全体像](specification.md) → 下の機能別仕様 |
| 実装を変更・検証したい | [内部設計](architecture.md) → [検証方法](testing/README.md) |

操作手順は「導入と運用」、機能の条件や例外は「機能の仕様」、実装と試験は「開発と検証」にまとめています。

## 利用者向けの操作

[掲示板の使い方](user-guide.md)に、閲覧・書き込み・削除依頼・回答の照会をまとめています。管理画面のアカウントは必要ありません。

## 導入と運用

| 文書 | 読む場面 |
| --- | --- |
| [Dockerなしのセットアップ](setup.md) | 初回起動、HTTPS公開、systemd登録、必要な構成の確認 |
| [Dockerセットアップ](../deploy/README.md) | Composeでの初期化、起動、更新、証明書管理 |
| [管理画面の使い方](admin-guide.md) | 画面の選び方、設定の保存、操作記録の検索、表示や権限で困ったとき |
| [運用手順](operations.md) | 日常管理、停止・再開、更新、バックアップ、障害からの復旧 |
| [設定一覧](configuration.md) | どこで設定するか、初期値、変更の反映時点 |
| [管理者の権限](admin-permissions.md) | ロール・担当板・追加権限の選び方と画面操作 |
| [セキュリティ運用](security-operations.md) | 公開入口、認証監視、暗号化バックアップ |

管理画面の「マニュアル」でも画面操作を確認できます。認証の登録・期限切れ時の対応は[管理画面ガイド](admin-guide.md#ログインと再認証)、各機能の条件や上限は下の仕様を参照してください。

サイト管理者向けの[ソフトウェア更新と再起動](software-updates.md)には、Docker・systemdそれぞれのホスト設定と確認画面の操作をまとめています。
