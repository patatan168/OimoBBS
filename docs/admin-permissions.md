# 管理者の権限

管理者の権限は、**ロール（できる操作）・担当板（操作する範囲）・追加権限（非公開情報の取り扱い）**で決まります。

- [ロールを選ぶ](#ロールを選ぶ)
- [追加権限を選ぶ](#追加権限を選ぶ)
- [権限を付与する](#権限を付与する)
- [表示されるメニュー](#表示されるメニュー)

## ロールを選ぶ

| 操作 | 投稿・スレッドの管理担当 | 板管理者 | サイト管理者 |
| --- | --- | --- | --- |
| 投稿削除・スレッド公開停止・投稿停止 | 担当板 | 担当板 | 全板 |
| 自動停止・通報の確認 | 担当板 | 担当板 | 全板 |
| 板設定・投稿規制・ローカルルール・CAPの管理 | 不可 | 担当板 | 全板 |
| 管理用スレッド一覧・操作記録の閲覧 | 不可 | 担当板 | 全板 |
| 削除依頼の閲覧・回答 | 追加権限が必要 | 担当板 | 全板 |
| 非公開記録の閲覧・保全・出力 | 追加権限が必要 | 担当板 | 全板 |
| サイト設定・板追加・管理者の権限付与・運用設定 | 不可 | 不可 | 可 |

投稿・スレッドの管理担当は、対象を指定した削除・公開停止・投稿停止の確認画面を利用できます。板設定・管理用スレッド一覧・操作記録の閲覧は、追加権限を付与しても許可されません。

サイト管理者以外は、選択した担当板だけを操作できます。担当板が未選択なら板を操作できません。サイト管理者は新しく追加した板も含め、全板を管理します。

## 追加権限を選ぶ

追加権限は次の2つです。投稿・スレッドの管理担当に、必要な項目を個別に付与します。板管理者・サイト管理者には両方が含まれます。

| 追加権限 | できること | 主な画面 |
| --- | --- | --- |
| 削除依頼の閲覧・回答 | 非公開の依頼本文・連絡先の確認と回答 | 削除依頼 |
| 記録の閲覧・保全・出力 | 投稿原本・接続元IPなどの照会、案件用コピーの保存・期限延長・解除、提出ファイルの出力・ダウンロード | 投稿管理・提出用ログ |

記録関連の操作は1つの権限で許可します。原本照会・保全・出力には、原則として10分以内の再認証が必要です。

**「記録の追加権限」と「管理操作の記録」は別の対象です。** 前者は投稿原本・接続情報などの非公開記録を扱う許可です。後者は、誰がいつ何を操作したかを示す要約で、板管理者以上が閲覧できます。

## 権限を付与する

サイト管理者が「管理者」画面で設定します。

1. 担当者の仕事に合うロールを選びます。
2. 操作を担当する板を選びます。
3. 投稿・スレッドの管理担当の場合は、必要な追加権限を選びます。
4. 選択内容を確認し、再認証して保存します。

| 選択したロール | 担当板のチェックボックス | 追加権限のチェックボックス |
| --- | --- | --- |
| 投稿・スレッドの管理担当 | 個別に選択 | 個別に選択 |
| 板管理者 | 個別に選択 | 両方チェック済み・変更不可 |
| サイト管理者 | 全板チェック済み・変更不可 | 両方チェック済み・変更不可 |

上位ロールから投稿・スレッドの管理担当に変更すると、自動で付いていた追加権限のチェックが外れます。必要な追加権限を選び直してください。

権限・パスワードの変更や無効化で、対象管理者の既存ログインは失効します。最後の有効なサイト管理者は、無効化・降格できません。

## 表示されるメニュー

| ロール | 表示するメニュー |
| --- | --- |
| 投稿・スレッドの管理担当 | 自動停止・通報、マニュアル。対応する追加権限がある場合だけ削除依頼・提出用ログ |
| 板管理者 | 板設定、操作の記録、キャップ、削除依頼、自動停止・通報、提出用ログ、マニュアル |
| サイト管理者 | すべての管理メニュー |

PC・スマホ共通で、権限のない項目はHTMLに出力しません。投稿管理画面の関連リンクとマニュアル内の管理画面リンクも同じ条件で表示します。再認証が必要な操作はメニューに表示し、実行時に[現在のログイン設定に応じた方法](features/administration.md#ログイン方法)で本人確認を求めます。

メニューを経由せずURLやAPIを指定しても、サーバーがロール・担当板・追加権限を検査します。再認証で不足する権限が増えることはありません。

管理ページのCSS/JSも、表示元HTMLと同じ認証・権限の条件を検査します。各画面で必要な資産だけを読み込み、管理用資産の共有キャッシュは許可しません。

認可・保存条件は[管理認証・権限・CAP](features/administration.md#管理者の役割と追加権限)、検査手順は[検証方法](testing/README.md#管理者権限)を参照してください。
