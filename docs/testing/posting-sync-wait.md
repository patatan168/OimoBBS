## 変更した収集の上限

以前は、確認画面・フォーム取得を含む64操作で一つの群を区切り、実際に保存する投稿が64件未満でも同期していました。投稿だけ論理操作を最大128件まで収集し、既に作った候補と構築中の候補を合わせて保存上限64件を保つ方式に変えました。追加操作は内容を実行するまで分からないため、全て保存候補にも確認結果にもなる可能性があるものとして保守的に予算を計算します。

最終版では完了済みの未保存結果も最大64件までとし、先に返した操作のclosureとcontext参照を解放します。既存の未完了129件・待機列128件、保存群64frame/8MiB、メモリ・ディスク予約は変えていません。通常の非投稿batchは従来どおり64操作です。異種操作のFIFO境界を越えず、途中で保存が区切られた群は追加収集を止めます。

同期APIの変更、Sync省略、未永続データの成功応答、WAF枠の拡大は行っていません。既存の16ms/2msの収集待ち方針も維持しています。
