## 実装した表示と操作

- 検出・拒否を7日間保持し、理由ごとの件数、本文例、比較相手、公開済み投稿へのリンクを表示します。種類・結果・ダミーで絞り込み、過去のページも確認できます。
- ログの本文例から全板共通NGワードの入力へ移動できます。本文をURLに載せず、再認証・条件の確認・保存後に適用します。
- 登録済み規制を画面上部に配置し、板別・全板共通の両方を条件／動作・投稿／期限／状態・操作の同じ列で表示します。状態別件数、全登録を対象とする検索、詳細の展開、条件を維持したページ送りを追加しました。
- 大量検出時は本文例を省略し、理由・結果別の件数を集約します。保存I/Oを待つことで通常投稿を止めないよう、固定長待機列が満杯の場合も件数をまとめます。
