# 掲示板の使い方

Web画面での閲覧・書き込み・削除依頼の手順です。一般利用者のアカウント登録やログインは不要です。

[文書一覧](README.md) · [管理者向けの操作手順](admin-guide.md)

## やりたいことから探す

| やりたいこと | 手順 |
| --- | --- |
| スレッドを読む・探す | [閲覧と検索](#閲覧と検索) |
| 返信する・スレッドを作る | [書き込み](#書き込み) |
| レスの削除を依頼する・問い合わせる | [削除依頼・問い合わせ](#削除依頼問い合わせ) |
| 運営からの回答を確認する | [受付済み依頼の照会](#受付済み依頼の照会) |
| 書き込みや依頼を送れない | [送信できないとき](#送信できないとき) |

## 閲覧と検索

トップから板を選び、スレッド一覧で読みたいスレッドを開きます。タイトル検索では、検索語と必要な条件を指定します。

期間は日本時間で指定します。期間の候補ボタンを使い、必要ならカレンダーで調整して検索してください。「今日」「昨日」は日本時間の暦日、「直近7日」などは現在からの経過時間です。開始日時を含み、終了日時を含まない範囲で検索します。

専用ブラウザーを使う場合は、そのアプリの手順で掲示板を登録します。通信先や文字コードは[閲覧・専ブラ通信の仕様](features/reading.md#閲覧と専ブラ向け通信)を参照してください。

## 書き込み

1. 返信する場合は対象スレッド、スレッドを作る場合は対象板の書き込み画面を開きます。
2. 本文などの必須項目を入力します。
3. 初回や利用規約が変わったときは、Cookieの説明と規約を確認して同意します。
4. 確認画面の対象と内容を読み、送信します。
5. 投稿結果を確認します。返信が受理されると、同じスレッドの最新50レスへ移動します。

Cookieの発行や確認画面の表示だけでは、投稿は完了していません。ブラウザーやアプリでCookieを保持できるようにしてください。利用規約は公開画面のフッターから確認できます。

通信が切れて結果が分からない場合は、まずスレッドを確認します。同じ要求の再送を扱う仕組みと条件は[通信切断と重複防止](features/posting.md#通信切断と重複防止)を参照してください。

## 削除依頼・問い合わせ

1. 対象レスの「削除依頼・問い合わせ」を開きます。
2. 自動入力された板名・スレッド番号・レス番号を確認します。
3. 種類と理由を入力します。連絡先は任意です。
4. 送信後に表示される**依頼IDと照会秘密を両方保存**します。照会秘密は一度だけ表示されます。

同じスレッドの複数レスは、`1,3-5` のように1件の依頼へまとめられます。理由と連絡先は公開しません。依頼の受付だけでは投稿は削除されません。

送信間隔はフォームに表示されます。初期値は同じブラウザーから10分に1件、同じ接続元IP全体で10分に3件です。管理者が間隔を変更でき、板・レス・依頼の種類を変えても共通の制限になります。

## 受付済み依頼の照会

「受付済み依頼の照会」に依頼IDと照会秘密を入力して、状態と運営回答を確認します。照会は、新しい依頼を送る間隔の制限とは別枠です。

照会秘密は他人に公開しないでください。管理者のログイン名やパスワードを使う欄ではありません。

## 送信できないとき

| 状態 | 次の操作 |
| --- | --- |
| Cookieや規約の確認が出る | 内容を確認して同意し、確認フローを完了する |
| 待機時間が表示される | 案内された時間を待つ。投稿と削除依頼では別の制限がある |
| 削除依頼の間隔に達した | 表示された待機時間の後に再送する。既存依頼の回答は照会できる |
| スレッドへの返信が停止している | 掲示板の案内に従い、返信できるスレッドを確認する |
| 保存できない・結果が分からない | 結果を確認してから再送する。同じ内容を別の新規投稿として連続送信しない |
| 削除されたレスが専用ブラウザーに残る | スレッドを再取得し、アプリに保存された表示を更新する |

投稿条件や規制の仕組みは[投稿の仕様](features/posting.md)と[投稿規制](features/abuse.md)、削除後のデータの扱いは[記録・削除・保持期限](features/records.md#レス削除あぼーんと原本)を参照してください。
